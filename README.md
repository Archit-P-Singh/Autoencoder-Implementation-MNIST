# Keras Autoencoders on MNIST

This repository contains a collection of Autoencoder architectures implemented using Keras (with a TensorFlow backend). The project explores unsupervised learning, dimensionality reduction, feature extraction, and image denoising by training various autoencoder models on the classic MNIST handwritten digit dataset.

##  Architectures Implemented

The `model/` directory contains five distinct autoencoder implementations to demonstrate different structural and regularization techniques:

1. **Simple Autoencoder (`autoencoder.py`)**: A baseline shallow network with a single hidden layer compressing the 784-dimensional input into a 2D latent space.
2. **Deep / Stacked Autoencoder (`stack_ae.py`)**: A deeper architecture with multiple hidden layers (128 -> 64 -> 10 -> 2) allowing the network to learn more complex, non-linear representations.
3. **Sparse Autoencoder (`sparse_ae.py`)**: Uses the deep architecture but applies **L1 Activity Regularization** to the hidden layers. This forces the model to learn sparse, robust features rather than simply memorizing the identity function.
4. **Denoising Autoencoder (`denoising_ae.py`)**: Demonstrates noise reduction. Artificial Gaussian noise is applied to the input images, and the network is forced to learn how to reconstruct the original, clean image from the corrupted input.
5. **Convolutional Autoencoder (`conv_autoencoder.py`)**: Replaces Dense layers with `Conv2D`, `MaxPool2D`, and `UpSampling2D` layers. This model excels at preserving spatial relationships in images, yielding the sharpest reconstructions.

##  Visualizing Results

Because the dense models compress the MNIST digits down to a **2-dimensional bottleneck layer**, the representations can be directly plotted on a 2D scatter plot. 

The `images/` directory contains outputs generated by the scripts:
* **Reconstructions (`_Comparison` / `_Mapping`)**: Displays the input images on the top row and the model's reconstructed output on the bottom row to visually evaluate performance.
* **Latent Space Clustering (`_plot`)**: A 2D scatter plot where each point is a compressed image, color-coded by its true digit label (0-9). This demonstrates how the autoencoder naturally clusters similar shapes together without being provided any labels during training.

##  Getting Started

### Prerequisites
To run the scripts, you will need the following libraries installed:
```bash
pip install numpy tensorflow keras matplotlib
```

### Running the Models
You can run any of the models directly from the terminal. For example, to train the Convolutional Autoencoder and view its outputs:
```bash
cd model
python conv_autoencoder.py
```
*Note: The MNIST dataset will be automatically downloaded by Keras upon the first run.*
